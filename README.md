# 📋 Factura

Programa el cual imprime una factura.

## ✨ Características

* 🛠️ Fácil de usar.
* 🎨 Colores visualmente informativos.
* 💻 Puede usarse para cálculos rápidos, incluso en teléfono.

## 🚀 Uso

Recibe las siguientes entradas a cerca de productos

* Tasa de interés (aplica a todos los productos)
* Precio
* Cantidad
* Descuento (opcional). Esto se desgloza en:
  * Predescuento
  * Descuento
  * Ahorro

y muestra los resultados en detalle.
